Spec: `docs/superpowers/specs/2026-11-26-utter-ui-v2-design.md` (read it fully; it is the authority).
Skills every frontend task applies: better-ui, better-typography, unslop (installed at
`~/.claude/skills/{better-ui,better-typography,unslop}`; read their SKILL.md before editing).

Waves (tasks in one wave run in parallel, each in its own git worktree):
- Wave 1: T1 Foundation (frontend) ∥ T3 Pill native (Rust)

## Cross-task contracts (fixed; do not change without the coordinator)

Frontend runtime appearance module `src/lib/appearance.ts` (T1 creates, T2 feeds):
- `applyAppearance({ theme, accentSource })` sets on `<html>`: `data-theme` + class `dark|light`
  (resolved from system when `theme === "system"`, live on `prefers-color-scheme` change),
  `data-reduce-motion` from `prefers-reduced-motion`, `--accent*` CSS vars when
  `accentSource === "windows"` and a system accent is known, `font-size` from text scale,
  `data-backdrop` (`mica` | `solid`).
- Backend events (T2 emits): `system://accent` `{ accent, light1, light2, light3, dark1, dark2, dark3 }`
  (strings `#rrggbb`), `system://text-scale` `{ factor: number }`, `system://backdrop`
  `{ kind: "mica" | "solid" }`.
- Command (T2 implements, T1 adds to `ipc.ts` + mock): `get_system_appearance` ->
  `{ accent: SystemAccent | null, textScale: number, backdrop: "mica" | "solid" }`.
- Setting (T2 adds to Rust settings, T1 adds to `types.ts` + mock defaults):
  `accentSource: "utter" | "windows"` default `"utter"`.

Pill (T3 Rust, T4 UI):
- `pill://levels`: `number[]` of length **9**, ~30Hz while recording, values 0..1 (spec §3 mapping).
- `pill://hover`: `{ hover: boolean }` — emitted on change only.
- `pill://visible`: not needed; visibility stays Rust-side.
- `PillAction` gains `"start"` (idle click -> start hands-free) and `"toggle"` (click while live ->
  stop and insert). Existing actions unchanged.
- Pill window logical size stays 360x72; capsule is drawn bottom-centred inside it. Rust's
  hover hit-test uses the capsule rect for the current state from `pill_capsule_rect(kind, hover)`
  (Rust mirror of the sizes in spec §3: idle 44x8, idle-hover 196x32, listening 148x36,
  locked 212x36, thinking 72x36, done 148x36, error 280x36; centred horizontally, bottom-aligned
  with 8px bottom margin inside the window). T4 must use exactly these sizes.

## T1 Foundation (frontend; wave 1)
Owns: `apps/desktop/package.json`, lockfile, `src/styles/*`, `src/main.tsx`, `src/pill.tsx` (only
the CSS import/transparency), `src/lib/appearance.ts` (new), `src/lib/ipc.ts`, `src/lib/mock.ts`,
`src/lib/types.ts` (only the additions above), `src/components/**` (AppShell, Sidebar, Logo,
ErrorBoundary, PlaceholderPage, ui/*).
1. Install `@heroui/react@^3` `@heroui/styles@^3` and the react-aria peers listed by npm. Remove
   `@fontsource/*`. Global CSS: `@import "tailwindcss"; @import "@heroui/styles";` then tokens.
2. Rewrite `tokens.css` to the spec palette/type ramp/radius/motion; map HeroUI variables; keep
   Tailwind utility names that pages use today where sensible (`bg-surface`, `text-muted`,
   `border-line`, `text-ink`, `bg-hover`, ...) so pages keep compiling, but drop `highlight*`.
   Add type-role utilities (`text-caption`, `text-body`, ... per spec table) via `@utility` or
   `@theme` `--text-*` with line-height and weight. Mica: transparent html/body when
   `data-backdrop="mica"`, opaque `--bg` otherwise.
3. `appearance.ts` per contract + call it from `main.tsx` and `pill.tsx` (pill: theme only, body
   stays transparent). Unit tests for the pure resolver (theme resolution, accent var selection,
   text-scale clamp 1..2.25).
4. Rebuild `components/ui/*` on HeroUI with the same exported names/props where possible
   (Button variants primary|secondary|ghost|danger, sizes sm|md, `icon`, `loading`; IconButton
   with `label` + Tooltip; Switch; Field/TextField/TextArea/Select; Card/CardSection; Kbd as keycap;
   EmptyState; PageHeader using `text-title`; Toast -> HeroUI `toast` + `Toast.Provider` in
   ToastHost; add Modal wrapper, Tabs, Tooltip, Spinner, ProgressBar re-exports as needed).
   Keep `onClick` working on Button/IconButton (map to `onPress`) so existing pages compile.
5. Shell: Sidebar 248px on the backdrop, nav rows 36px, 20px icons stroke 1.5, active = raised
   surface + 3px ember indicator on the left (Windows NavigationView), wordmark at top; content
   column on the layer surface with 8px top-left radius; remove the "Powered by Claude Haiku"
   footer. Content max width 1040, padding 32.
6. Fix tests that depended on removed markup; all existing tests pass. `npm run typecheck`,
   `lint`, `test`, `build` green. Screenshot Home light+dark via the preview server.

## T3 Pill native (Rust; wave 1)
Owns: `src-tauri/src/windows.rs`, new `src-tauri/src/pill_windows.rs` (Win32 bits),
`src-tauri/src/audio/dsp.rs` (`level_bars`), `src-tauri/src/audio/capture.rs` (LEVEL_BARS, emit
cadence), the pill parts of `app_state.rs`, pill action handling in `commands.rs`, Cargo.toml
`windows` features, `lib.rs` (only to start the keeper).
1. Pure + tested: `pill_rect(work, scale)` with 12px gap; `pill_capsule_rect(kind, hover)` per
   contract; `level_bars(window, 9)` with spec mapping (-55..-10 dB, pow 0.7); `hide_for_quns(state)`
   (true for QUNS_BUSY, QUNS_RUNNING_D3D_FULL_SCREEN, QUNS_PRESENTATION_MODE); `monitor_changed`.
2. Window styles at creation: add `WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE | WS_EX_TOPMOST`
   (GetWindowLongPtrW/SetWindowLongPtrW + SWP_FRAMECHANGED); subclass (SetWindowSubclass,
   comctl32 feature) returning `MA_NOACTIVATE` for `WM_MOUSEACTIVATE`. If WebView2's child
   receives the click, also subclass is not possible there — document and rely on NOACTIVATE.
3. Keeper thread (Windows): own message loop; `SetWinEventHook(EVENT_SYSTEM_FOREGROUND, ...,
   WINEVENT_OUTOFCONTEXT)` + 1500ms timer -> re-assert `HWND_TOPMOST` with `SWP_NOMOVE |
   SWP_NOSIZE | SWP_NOACTIVATE` when the pill is visible; 60ms cursor poll while visible ->
   hit-test against the capsule rect (physical px) -> `set_ignore_cursor_events(!inside)` +
   `pill://hover` on change; 500ms monitor-follow while idle; hide idle pill when
   `SHQueryUserNotificationState` says fullscreen/presentation/busy and show again after.
   All Tauri window calls marshalled to the main thread (`run_on_main_thread`).
4. Idle visibility: `sync_pill` shows the idle pill whenever allowed (it already does); make
   sure startup calls it after the pill window is created and after onboarding completes.
5. Pill actions: `"start"` -> same path as the HandsFree hotkey press (start locked dictation);
   `"toggle"` -> stop and insert if live. Unit-test the action routing where pure.
6. Levels: LEVEL_BARS = 9, emit ~30Hz (33ms window) while recording.
7. `cargo test --lib`, clippy -D warnings, fmt check green (x64 env from parallel-env.md).
