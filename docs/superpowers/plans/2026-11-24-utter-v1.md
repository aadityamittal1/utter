# Utter v1 (Windows) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Utter v1 — a free, open source Windows (x64 + ARM64) dictation app: hold a hotkey, speak, and local Whisper + Claude Haiku put clean text into any app; plus snippets, dictionary, styles, enhance, command mode, transforms, notes, history, insights, onboarding, full brand kit and open source repo.

**Architecture:** Tauri v2 app in `apps/desktop`. A Rust core owns everything OS-level and the dictation pipeline (hook → audio → whisper → text rules → Claude → paste → store); pure logic lives in small, unit-tested modules. A React/TypeScript UI renders two windows (Hub incl. onboarding, and the Pill overlay) and talks to Rust only through the IPC contract below. The UI also runs in a plain browser against a mock backend for development and visual checks.

**Tech Stack:** Rust (stable, edition 2021), Tauri 2, whisper-rs 0.16, cpal, rubato, hound, windows (Win32), arboard/clipboard-win, enigo 0.6, rusqlite (bundled), keyring 4, reqwest (rustls), tokio, serde; React 19, TypeScript strict, Vite, Tailwind CSS 4, Zustand, Lucide, @fontsource (Inter, Instrument Serif, JetBrains Mono), Vitest.

**Spec:** `docs/superpowers/specs/2026-11-24-utter-design.md` — read it before your task.

## Global Constraints

- Platform v1: **Windows only** (x64 + ARM64). Put Windows-specific code in `*_windows.rs` / `cfg(target_os = "windows")` modules behind a small platform-neutral function so macOS can be added later. Dev machine is Windows 11 ARM64.
- App identifier `dev.utter.app`; product name `Utter`; Rust package `utter` (lib `utter_lib`); repo `aadityamittal1/utter`; license MIT, `Copyright (c) 2026 Utter contributors`.
- Claude API: raw HTTPS `POST https://api.anthropic.com/v1/messages`, headers `x-api-key`, `anthropic-version: 2026-10-21`, `content-type: application/json`. Never send `temperature`, `top_p`, `top_k`. Default model `claude-haiku-5-5`; optional `claude-sonnet-5-5`. Cleanup: `"thinking": {"type": "disabled"}`. Enhance/Command/Transform: `"thinking": {"type": "adaptive"}, "output_config": {"effort": "low"}`. Always check `stop_reason` (`refusal`, `max_tokens` → treat as failure). Key validation uses `GET /v1/models` (free).
- Pricing table for cost estimates (USD per million tokens, input/output): Haiku 5.5 `0.10/0.50`, Sonnet 5.5 `2.00/10.00`.
- Any Claude failure (no key, network, timeout 15 s, 4xx/5xx, refusal, max_tokens, rejected output) → fall back to local cleanup; dictation is never lost. Command mode without a key → pill error "Add an API key to use commands".
- Audio never leaves the machine. No telemetry. API key only in Windows Credential Manager via `keyring` (service `dev.utter.app`, user `anthropic_api_key`); never in settings, logs, or errors.
- Default shortcuts (Windows): Dictate `Ctrl+Win` (hold); Hands-free `Ctrl+Win+Space` (toggle) and double-tap Dictate within 400 ms; Dictate & enhance `Ctrl+Win+Shift` (hold); Command `Ctrl+Win+Alt` (hold); Cancel `Esc` (only while recording); Paste last `Alt+Shift+Z`; Copy last `Alt+Shift+C`; Polish `Alt+Shift+1`; Prompt engineer `Alt+Shift+2`; Quick note `Alt+Shift+N`.
- Recordings < 0.4 s are discarded; max 20 min, warning at 19 min.
- Limits: dictionary entry ≤ 60 chars; snippet trigger ≤ 60 chars, expansion ≤ 4,000 chars; ≤ 8 custom transforms.
- Brand tokens: Ink `#14131A`, Paper `#FAF8F5`, Ember `#FF5A36`, Ember dark `#E0401E`, Lilac `#8B7CF6`; fonts Inter (UI), Instrument Serif (display), JetBrains Mono (code), all bundled offline via @fontsource. Text "Powered by Claude Haiku" only — no Anthropic or Wispr marks or copy.
- Pure-logic modules get unit tests first (TDD). Run from `apps/desktop/src-tauri`: `cargo test --lib`. UI: `npm run typecheck && npm run lint && npm test` from `apps/desktop`.
- Do not `git commit` inside an implementer task unless your task says so; the coordinator commits after review. Never push.

## Review Focus

1. **Claude does something other than clean the text** — the dictation is a question ("what's the capital of France"), adds a preamble ("Here's the cleaned text:"), wraps in quotes, or drops a snippet placeholder. Expected: the user's own words, cleaned; never an answer. → Task 5 tests `extract_output` and the prompt guard; Task 10 tests `accept_ai_output` rejects answers/preambles/missing placeholders and falls back.
2. **Silence or noise** — user taps the key and says nothing, or whisper returns `[BLANK_AUDIO]` / "Thank you." on silence. Expected: nothing pasted, pill says "Didn't catch that". → Task 3 tests `strip_artifacts`; Task 10 tests `plan_route` returns `Nothing` for empty text and low-energy audio.
3. **Clipboard edge cases** — clipboard holds an image/file list or is empty, or the user copies something within the restore window. Expected: original clipboard restored when it's safe, never clobbering a new copy, never a crash. → Task 8 tests `should_restore` and snapshot round-trip of non-text formats.
4. **Hotkey chord collisions** — `Ctrl+Win` then `Shift` (enhance), `Ctrl+Win+→` (switch desktop), Win released last (Start menu pops), injected paste keys re-entering the hook. Expected: right action fires, desktop switch isn't hijacked, Start menu never opens, no feedback loop. → Task 9 matcher tests cover each case.
5. **Modifiers still held at paste time** — snippet-only path pastes instantly while the user is still releasing `Win`, producing `Win+Ctrl+V`. Expected: paste waits for physical modifier release (≤ 1 s). → Task 8 `wait_for_modifiers_released` is called by `insert_text` and tested via an injectable key-state fn.
